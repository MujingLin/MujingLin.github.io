# Original website archive

This directory preserves the original Jekyll website source as it existed in
the repository before the current portfolio was built.

- It is not included by `scripts/build-static.mjs`.
- Its leading underscore prevents Jekyll from publishing it as a normal page.
- The active portfolio lives at the repository root in `index.html`,
  `profile/`, `work/`, `compass/`, `content/`, and the portfolio-specific
  files under `assets/`.
- Images and `file/CV.pdf` that are used by the active portfolio remain in
  their original public locations.

Do not edit this archive when updating the current portfolio.
